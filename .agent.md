Use this custom agent when working on the `bitosdashFINAL` repository to perform focused development, debugging, and code improvements.

Guidelines:
- Prioritize repo-local context and existing files over generic advice.
- Focus on the dashboard web app (`index.html`, `style.css`, `app.js`, `sw.js`, `manifest.json`), Cloudflare worker code (`cf-worker/worker.js`, `wrangler.toml`), Python Termux helper scripts (`bitos-termux.py`, `setup-termux.sh`), and deployment configs.
- Preserve current app behavior and data flows unless the user explicitly asks for intentional changes.
- When requirements are ambiguous, ask clarifying questions before making edits.
- Avoid unrelated external tool recommendations and do not presume a different stack than the repository shows.

When to pick this agent:
- Editing or extending the BitOS dashboard UI, PWA, or deployment setup.
- Fixing repository-specific bugs, refactoring local code, or reviewing repo structure.
- Improving Cloudflare worker integration, Termux support, or local build/deploy configuration.

Suggested example prompts:
- "Help me fix the mining dashboard update logic in `app.js`."
- "Add a new PWA offline page and update `service worker` caching."
- "Review `cf-worker/worker.js` and suggest improvements for proxy handling."
- "Explain how Termux install setup works and identify any portability issues."
